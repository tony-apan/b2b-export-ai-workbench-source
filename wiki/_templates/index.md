## 选择规则

| 你要新建什么 | 首选模板 | 什么时候不要用它 |
|---|---|---|
| 普通知识、规则或判断页面 | [page.md](page.md) | 已经有更窄的 concept / playbook / decision 模板时 |
| 长期复用概念 | [concept-page.md](concept-page.md) | 只是当前客户或当前项目事实时 |
| 可执行 SOP | [playbook.md](playbook.md) | 只有一个临时动作、尚未验证时 |
| 业务事实、ICP、offer、异议或证据 | [client-profile.md](client-profile.md)、[competitor-profile.md](competitor-profile.md) | 不能把真实客户资料放入公开母库 |
| 来源提炼 | [source-note.md](source-note.md) | 原文转写应使用 [raw-extracted-markdown.md](raw-extracted-markdown.md) |
| 实验 | [experiment-record.md](experiment-record.md) 或 [geo-test-log.md](geo-test-log.md) | 没有 baseline、指标和停止规则时 |
| 验证证据 | [verification-record.md](verification-record.md) | 不要用“测试通过”代替发布批准 |
| 执行后的知识回写 | [writeback-record.md](writeback-record.md) | 不能只改输出页而不记录新证据 |
| 公开发布审查 | [publication-review.md](publication-review.md) | 许可证、授权或去敏未完成时 |
| Skill / 子库发布合同 | [skill-spec.md](skill-spec.md)、[sub-library-publish-manifest.md](sub-library-publish-manifest.md) | 子库本体不得被一份 Skill 文案替代 |

## 新建页面最小闭环

1. 复制最窄模板并改名，不直接复制已有业务页面。
2. 补写真实 `title`、人话 `description`、`type`、`status`、`created`、`last_updated`。
3. 填写 `sources`、`related`、适用范围和不适用边界；无来源写 `[]` 并把结论降级为待验证。
4. 如果页面属于一个被导航的目录，运行 `node scripts/sync-indexes.mjs`。
5. 运行 `node scripts/validate-indexes.mjs`，再按任务需要更新 registry、ingestion-log、open-questions 或 release evidence。

## 不应模板化的 singleton

根 `AGENTS.md`、`CLAUDE.md`、`README.md`、`LICENSE.md`、`VERSION.md`、`CHANGELOG.md` 和母库 / 子库 `MANIFEST.md` 不应被普通页面模板覆盖。它们有自己的发布合同，只能按对应规范更新。
