# Course Modules Index

## 课程不是 raw 的复制品

课程模块必须经过“来源登记 → 事实/冲突提取 → 稳定概念或 playbook → 教学任务 → 练习 → 验收 → 结果写回”。一次原始对话最多提供一个待验证案例，不能直接升级为通用结论。

## 推荐阅读顺序

1. 先读 [raw/index.md](../../../raw/index.md) 了解来源边界。
2. 再读 [source-registry.md](../../10_sources/source-registry.md) 确认来源状态。
3. 找到对应的 concept/playbook，确认哪些内容已经稳定。
4. 使用 [course-module.md](../../_templates/course-module.md) 创建模块。
5. 将练习结果写入验证记录和 writeback，必要时回写 concept、playbook、指标或 open questions。
