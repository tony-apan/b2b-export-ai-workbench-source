# B2B Export Module Map

外贸 B2B 不只是 LinkedIn 和开发信。建议把知识库逐步扩展成以下模块。

## Customer And Market

| Module | Why It Matters | Current Status |
|---|---|---|
| ICP / Buyer Persona | 不同国家、行业、职位、采购角色差异很大 | Existing |
| Market Selection | 选择国家、区域、行业和应用场景 | Candidate |
| Competitor Intelligence | 竞品价格、认证、渠道、内容、展会打法 | Existing |
| Customer Voice | 客户原话、询盘、异议、成交原因 | Candidate |

## Product And Trust

| Module | Why It Matters | Current Status |
|---|---|---|
| Product Content System | 参数、应用场景、卖点、FAQ、认证、包装 | Candidate |
| Certification / Compliance | 外贸 B2B 常受认证、标准、合规影响 | Candidate |
| Case Study System | 案例是网站、LinkedIn、开发信、销售的共同燃料 | Existing |
| Proof Library | 统一管理截图、评价、数据、授权 | Existing |

## Acquisition Channels

| Module | Why It Matters | Current Status |
|---|---|---|
| Website / Landing Pages | 承接信任和转化 | Existing |
| LinkedIn | B2B 人脉、内容和私信 | Existing |
| Email Outreach | 主动开发客户 | Existing |
| SEO | 长期需求入口 | Existing |
| GEO / AI Search | AI 答案中的品牌可见性 | Existing |
| SEM / Ads | 测试和放大高意图流量 | Existing |
| Short Video | 产品演示、工厂展示、案例、教育内容 | Candidate |
| Trade Shows | 展会前中后获客闭环 | Candidate |
| B2B Marketplaces | Alibaba、Made-in-China、Global Sources 等 | Candidate |
| Partner / Distributor | 渠道商、代理商、合作伙伴拓展 | Candidate |

## Sales And Operations

| Module | Why It Matters | Current Status |
|---|---|---|
| Sales Call / Negotiation | 资格判断、异议、报价和推进 | Existing |
| RFQ / Inquiry Handling | 外贸询盘处理速度和质量影响成交 | Candidate |
| Pricing / Quotation | 报价结构、MOQ、样品、付款、交期 | Candidate |
| CRM / Follow-up | 长周期跟进和机会管理 | Candidate |
| Delivery / After-sales | 交付、售后、复购、转介绍 | Candidate |

## Content Production

| Module | Why It Matters | Current Status |
|---|---|---|
| Visual Design SOP | LinkedIn 图、广告图、产品图、信息图 | Candidate |
| Video Production SOP | 产品视频、工厂视频、客户案例视频 | Candidate |
| Short Video Ops | 短视频选题、脚本、拍摄、发布、复盘 | Candidate |
| Translation / Localization | 多语言和不同市场表达 | Candidate |

## Recommended Next Modules

优先级建议：

1. Product Content System：所有渠道都依赖产品和场景表达。
2. Customer Voice：把询盘、聊天、评论、销售电话沉淀成客户语言。
3. Visual Design SOP：LinkedIn、Ads、网站都需要图。
4. Video Production SOP：外贸产品展示和信任建立很需要视频。
5. RFQ / Inquiry Handling：从线索到商机的关键环节。
