# 学习与演练地图

1. 理解 Core / Template / Runtime 边界；
2. 初始化空运行区；
3. 建立一个 synthetic 客户和任务；
4. 记录聊天、输出、日志、证据和 handoff；
5. 建立第二个同名产品、同渠道客户并验证隔离；
6. 运行 scope search 与 boundary validator；
7. 运行 core update check，确认不会覆盖 runtime；
8. 完成写回候选的去标识化审核。
