# FluxPedal Motors ICP 卡

## 首个目标客群

中小型电动自行车品牌、货运 e-bike 整车团队和方案集成商，正在开发或升级 20 英寸货运车型，需要选择轮毂电机和整套动力匹配方案。

## 购买角色

| 角色 | 关心什么 | 内容任务 |
|---|---|---|
| Founder / Product Manager | 上市时间、差异化、成本和供应风险 | 选型指南、比较页、项目流程 |
| Mechanical / Electrical Engineer | 安装尺寸、扭矩、控制器、电池、热和测试 | 规格、计算输入、接口和验证清单 |
| Purchasing Manager | MOQ、价格、交期、变更和供应稳定 | RFQ 清单、打样和量产流程 |
| Compliance / QA | 目标市场要求、测试资料、追溯 | 合规问题清单，不做无证据承诺 |

## 触发事件

- 新开发 cargo e-bike；
- 现有 250W 方案爬坡或载重体验不足；
- 从 26 英寸车型迁移到 20 英寸平台；
- 需要第二供应商或定制线束 / 接口；
- 样车阶段出现过热、噪音、效率或控制器匹配问题。

## 暂不作为首轮目标

- 只购买单个零售替换件的消费者；
- 只问最低价、不提供整车和应用参数的询盘；
- 要求未经验证的法规或性能保证的项目。
