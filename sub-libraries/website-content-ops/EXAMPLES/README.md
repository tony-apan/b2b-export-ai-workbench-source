## Canonical 示例路由

### FluxPedal Motors：完整四记录 fail-closed package

[FluxPedal Motors 电动自行车电机出口商](fluxpedal-motors/README.md)用于演示 Article Brief、Article Draft、Article Quality Review 与 Publish Record 的完整四记录闭环，以及自然语言六节点痛点链、六槽 conversion surface、逐行 digest 绑定的 CTA measurement plan、事实、证据、发布和验证边界。它是 synthetic fixture，不是客户案例；本地结构 PASS 也不证明真实搜索需求、analytics、排名、询盘、转化、收入、Stable、Published 或 production-ready。

### SignalForge Controls：买家可见 positive Draft fixture

[SignalForge Controls 伺服驱动 readiness 文章](signalforge-controls/README.md)用于复制和评审买家可见的文章结构：frontmatter 保留页面 H1，唯一 publishable marker 内从 H2 开始，并展示 fit/exclusion、痛点到决策、worksheet、内链语境、review gate 与分层 CTA。它不是完整四记录 package，也不证明 CMS/renderer、真实 SEO、排名、询盘、转化或收入效果。

选择规则：需要验证完整内容包合同时走 FluxPedal；只需要借鉴可发布正文的信息层级和买家扫读结构时走 SignalForge。两份示例都不能作为真实业务效果证据。
