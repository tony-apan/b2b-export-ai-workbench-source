# 图片对抗审查清单（美学 + 用户心理）

> 用法：每张要上站的图发布前过一遍；配合 image-manifest（来源/许可/尺寸/alt 登记）使用。

## A. 硬性门（不过 = 不发布）
- [ ] 分辨率：主图/Hero ≥1200px 宽；内容卡 ≥800px；放大后无明显锯齿
- [ ] 文件：jpg/webp；≤500KB/图（超则压缩）；无水印/无截图裁切痕迹
- [ ] 格式与 alt：alt 描述"内容+场景"（非关键词堆砌）；扩展名带 .jpg/.webp
- [ ] 许可：来源+author+license 已登记 image-manifest（CC/PD/自有）；无版权不明图

## B. 审美（视觉质量）
- [ ] 主体清晰：主体占比 ≥50%、背景不抢戏、无杂乱主体（半张脸/车辆挡住/杂物）
- [ ] 构图稳定：有视线引导/留白；不歪斜不贴边；明暗均匀（无死黑死白）
- [ ] 风格一致：同站色调/摄影角度/后期风格统一（避免"拼贴感"）
- [ ] 裁切安全区：缩略图/社交卡（方形）裁切后主体仍在中央

## B·六、图片三分离架构（评审 6 轮定稿）
- 文章 Hero=公共场景图（氛围/版权清晰 PD 优先）
- 产品推荐卡=**真实产品图**（无素材=不假冒，记录 BLOCK 待素材——用场景图顶替会削弱购买信任）
- 正文辅助图=尺寸/装载/舱位细节图（平台正文图块 ❌ → 待平台/素材）
- **禁止**同一张场景图同时当封面+产品证明图（资源同步便利 ≠ 视觉正确）

## B·五、品牌与选图（评审 4 轮新增）
- **无第三方品牌标识**（logo/桨/活动名——Aqua Bound 案例教训）；看不清的小标识也避免
- 主体清晰：核心主体（船/人）无前景遮挡（帽子/局部人脸/树枝）
- 产品证明力：文章主图=产品/场景证明（"图像中的船=讨论的产品"更优）；纯活动图降级为辅助
- 首选：自有产品图 > 无品牌公共场景图（PD 优先）> 品牌活动现场图（最后选）
- 移动端裁切后主体仍完整

## C. 用户心理（结合页面目的）
- [ ] 产品主图 = 使用场景（唤起"我也想拥有"）而非纯白底官方照；白底图只作规格辅助
- [ ] 细节图 = 品质证据（做工/材质/密封——说服"值这个价"）
- [ ] 人物图 = 可信度（真实感；表情自然；人物与品类相关）
- [ ] 情绪匹配：B2B 出口站用"专业/可靠"；消费站用"愉悦/憧憬"——不混用
- [ ] 同页图片不重复同一张（分类卡/hero/详情错开），颜色搭配页面主题

## D. 页面语境
- [ ] 每图有明确用途（hero/内容卡/证书/场景），无"装饰性无关图"
- [ ] 图片与相邻文案语义一致（图说"封盖密封"，文案别写"容量"）
- [ ] loading/fit 设置合理（cover 裁切预览确认主体不丢失）

## E. 工具门
- [ ] `image-check.py`（尺寸/大小/重复）通过；截图人工复核再上一轮
