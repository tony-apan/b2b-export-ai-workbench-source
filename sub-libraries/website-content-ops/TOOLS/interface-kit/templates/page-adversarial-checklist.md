# 产品/单页对抗审查清单（每区块前向审查："客户看到这里心里想什么"）

> 用法：产品页/首页/公司页/联系页每个区块发布前过一遍；不通过的下拉思维：**客户喜欢吗？痛在哪？为什么喜欢？能不能更强？**

## 1. 首屏（3 秒法则）
- [ ] 3 秒内说清：这是什么 + 客户得到什么（图/标题/CTA 三者齐）
- [ ] 标题 = 利益句（"68cm 稳，第一趟就不晃"），不是属性堆（"68cm beam"）
- [ ] CTA 唯一且动作明确（Shop/Ask/Read）

## 2. 利益化翻译（属性 → 利益）
- [ ] 每个规格（材质/尺寸/重量/容量）都有一条"这意味着客户……"的说法
- [ ] 出现客户原话级情感词（"不用担心漏水"而不是"密封性好"）

## 3. 痛点回应（对照 customer-voice）
- [ ] 产品页覆盖该品类客户的 TOP 3 决策顾虑（如稳定性/容量/发货/售后），每条有答案
- [ ] FAQ 与正文不重复、每个问题绑定一个真实买家任务

## 4. 证据与差异化（为什么买你）
- [ ] 至少一个"同价位为什么选我们"的差异化句（实测口径/可展示细节/服务承诺）
- [ ] 无编造声明；demo 内容显式标注
- [ ] 有价格标签时说明包含什么（不含什么）

## 5. 视觉层级与路径（单页结构）
- [ ] 区块顺序匹配决策路径：先看懂（hero）→ 再信任（规格/证据）→ 再行动（CTAs）
- [ ] 每区块有单一视觉焦点（一张图一个主题）；同页图片不重复
- [ ] 无"模板味"区块（分类卡/评价/Q&A 内容全部品牌化，不残留模板文案）

## 6. 心理检查（为什么喜欢）
- [ ] 场景图唤起使用憧憬（"我也想去那天"）
- [ ] 细节图提供品质证据（材质/做工/密封）
- [ ] 社会证明（评价/案例）用具体细节而非"好评如潮"
- [ ] 紧迫性/稀缺性只用真实事实（库存/交期），不伪造

## 7. 验证门
- [ ] 截图人工复核（桌面 1440 + 移动 390）；readback diff 无害；residue gate pass
