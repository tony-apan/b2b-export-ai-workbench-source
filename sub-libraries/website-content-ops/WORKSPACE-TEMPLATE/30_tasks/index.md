## 状态真源边界

本目录不记录 task status、owner、approval、blocker 或完成度。上述字段只以外部 `agency-operations` runtime 的 `TASK.json` 与 `task-registry.jsonl` 为机器真源；`HANDOFF.md` 只做人类可读续接。没有准确 `client_id + company_id + task_id` 时，不得在这里创建任务记录或搜索客户数据。

批量前仍必须具备字段映射、单样本结果和人工批准；失败使用 [失败诊断模板](../TEMPLATES/failure-diagnosis.md)，并把事件写回当前 scoped task，而不是手改本索引。
