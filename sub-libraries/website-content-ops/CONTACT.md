# 联系与支持

如果你遇到以下情况，可以微信联系 Tony：

- 还没有 AllinCMS 账号或网站；
- 不知道应该登录哪个站点；
- 想了解 AI 建站内容运营怎么落到自己的业务；
- 需要模板、Adapter、内容迁移或失败排查支持。

添加微信时建议备注：**建站内容运营 / AllinCMS**。

## 安全提醒

- 二维码是公开联系入口，不是系统登录凭据；
- 不要在公开仓库、Issue 或 Markdown 中提交密码、Cookie、Token、Secret、客户名单或经营数据；
- AI 可以帮助检查环境，但不能代替账号开通、授权确认或真人发布批准；
- 工程、法规、认证和法律事项仍需对应专业人员确认。
