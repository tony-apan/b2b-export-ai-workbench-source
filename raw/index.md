# Raw Source Intake Index

## 先看这里

`raw/` 是事实输入层，不是课程目录，也不是结论目录。原始对话、网页抓取、PDF 转写和导出文件按来源形态分类保存；提炼出的事实、判断、SOP 和课程模块必须写入 `wiki/` 或 `wiki/90_outputs/courses/`，不能把 raw 改写成总结页。

当前母库远程为私有 canonical 仓，但 Git 私有不等于客户运行区。凭据、账号导出、真实客户经营数据和受限课程原文仍进入独立私有运行区；公开子库只能取得经过 manifest allowlist、去敏和授权审查的摘要或 synthetic fixture。

## 处理闭环

```text
raw/ 分类归档
  -> wiki/10_sources/source-registry.md 登记 Source ID
  -> 提取 facts / quotes / conflicts / questions
  -> wiki/20_concepts/ 或 wiki/30_playbooks/ 提炼稳定知识
  -> wiki/90_outputs/courses/ 组织课程模块
  -> 练习、验证、复盘
  -> writeback 记录回写来源、指标和边界
```

每个原始资料应有 `source_id`、采集时间、来源渠道、敏感级别、同意状态和当前吸收状态。不要把 AI 的总结、建议或未经验证的推断混进原始文本。
